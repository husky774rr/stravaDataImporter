🚀 ようこそ！

Strava Data Importer は、Strava のアクティビティデータを自動で取得・蓄積し、 トレーニングの分析に役立てるツールです。

  • 📊
    アクティビティデータの自動取得 Strava API から 1 時間ごとにアクティビティを自動収集します。
  • ⚡
    TSS / NP の自動算出 FTP を基にトレーニングストレススコア (TSS) と Normalized Power (NP) を算出します。
  • 📅
    週・月・年の集計 週間・月間・年間の走行距離、運動時間、獲得標高、TSS を集計します。
  • 🐦
    SNS (X) への自動投稿 アクティビティ完了時に TSS、NP などの情報を X に自動投稿します。

🔐 Strava との連携

以下の手順に従って Strava アカウントと連携してください。

  1. 1
    「認証を開始する」ボタンをクリック ボタンをクリックすると Strava の公式認証ページへ移動します。
  2. 2
    Strava にログイン Strava のメールアドレスとパスワードでログインしてください。 既にログイン済みの場合はスキップされます。
  3. 3
    アクセスを許可 「アクセスを許可する」ボタンをクリックして、 このアプリへのデータアクセスを承認してください。
  4. 4
    連携完了 → ポータルへ 承認完了後、自動的にポータル画面へ遷移します。
